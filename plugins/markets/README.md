# Market Tools

Technical indicators over a price series, candlestick charts for a ticker, liquidity pool fee and volume checks, and token red-flag screens.

```bash
claude plugin install markets@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `market-indicators` | Market Indicators | `https://indicators.openkrill.app/mcp` |
| `trade-chart` | Trade Chart | `https://chart.openkrill.app/mcp` |
| `lpcheck` | LP Pool Check | `https://lpcheck.openkrill.app/mcp` |
| `cryptodd` | Crypto Due Diligence | `https://cryptodd.openkrill.app/mcp` |

Every server is public, read-only and needs no key.
