# Consumer Checks

US recalls, car reports by VIN, food facts by barcode, and travel advice with live airport status.

```bash
claude plugin install consumer@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `recalls` | Recall Check | `https://recalls.openkrill.app/mcp` |
| `cars` | Car Check | `https://cars.openkrill.app/mcp` |
| `food` | Food Facts | `https://food.openkrill.app/mcp` |
| `travel` | Travel Check | `https://travel.openkrill.app/mcp` |

Every server is public, read-only and needs no key.
