# Store and Trade Tools

Store price tracking, catalog and feed checks, HS codes, duty and landed cost, US product-safety certificates, and competitor ad angles.

```bash
claude plugin install commerce@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `store-prices` | Store Price Tracker | `https://stores.openkrill.app/mcp` |
| `catalog-qa` | Catalog QA Desk | `https://catalogqa.openkrill.app/mcp` |
| `tariffs` | Tariff & HS Code Duty Finder | `https://tariffs.openkrill.app/mcp` |
| `shop-duty` | Shop Duty Desk | `https://shopduty.openkrill.app/mcp` |
| `certpacket` | CertPacket | `https://certpacket.openkrill.app/mcp` |
| `ad-angle` | Ad Angle Map | `https://adangle.openkrill.app/mcp` |

Every server is public, read-only and needs no key.
