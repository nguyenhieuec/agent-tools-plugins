# Research and Public Data

Find papers, check references and DOIs, read US federal regulations, compare country statistics, and make a school digest.

```bash
claude plugin install research@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `papers` | Paper Finder | `https://papers.openkrill.app/mcp` |
| `citations` | Citation Checker | `https://citations.openkrill.app/mcp` |
| `rules` | US Federal Regulations (CFR) | `https://rules.openkrill.app/mcp` |
| `countrystats` | Country Stats Facts | `https://countrystats.openkrill.app/mcp` |
| `school-digest` | School Digest | `https://schooldigest.openkrill.app/mcp` |

Every server is public, read-only and needs no key.
