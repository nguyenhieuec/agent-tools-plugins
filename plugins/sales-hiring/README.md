# Sales, Jobs and Hiring

Buyer signals, an inbound pitch scoreboard, open jobs at named companies, remote jobs by country, and a hire-or-automate split.

```bash
claude plugin install sales-hiring@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `buyersignals` | Buyer Signals | `https://signals.openkrill.app/mcp` |
| `outreach-desk` | Outreach Desk | `https://outreachdesk.openkrill.app/mcp` |
| `company-jobs` | Company Jobs Finder | `https://jobs.openkrill.app/mcp` |
| `remote-jobs` | Remote Jobs by Country | `https://remotejobs.openkrill.app/mcp` |
| `hire` | Hire or Automate | `https://hire.openkrill.app/mcp` |
