# Developer and Security Checks

Package health, CVE triage, software end-of-life and licence facts, DESIGN.md lint and diff, and AI coding agent news.

```bash
claude plugin install dev-security@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `packages` | Package Health Check | `https://packages.openkrill.app/mcp` |
| `cve` | CVE Risk Check | `https://cve.openkrill.app/mcp` |
| `dev-facts` | Dev Facts Check | `https://devfacts.openkrill.app/mcp` |
| `design-md` | DESIGN.md Linter & Extractor | `https://designmd.openkrill.app/mcp` |
| `industry-pulse` | Industry Pulse | `https://pulse.openkrill.app/mcp` |
| `agent-trace` | Agent Trace Check | `https://agenttrace.openkrill.app/mcp` |
| `injection-scan` | Prompt Injection Scanner | `https://injectionscan.openkrill.app/mcp` |

Every server is public, read-only and needs no key.
Generated from the Agent Tools plugin listings; edits made here are overwritten.
