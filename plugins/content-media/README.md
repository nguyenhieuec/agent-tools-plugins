# Content and Media Tools

Post and video script drafts, AI-writing checks, transcripts, free video, Live Photos, design taste, plus YouTube transcripts, app reviews and X posts.

```bash
claude plugin install content-media@openkrill
```

| Skill and MCP server | Tool | Endpoint |
| --- | --- | --- |
| `postkit` | Post Kit | `https://postkit.openkrill.app/mcp` |
| `ai-text` | AI Text Check | `https://aitext.openkrill.app/mcp` |
| `transcript-kit` | Transcript Kit | `https://transcript.openkrill.app/mcp` |
| `videograb` | Video Grab | `https://videograb.openkrill.app/mcp` |
| `live-card` | Live Card | `https://livecard.openkrill.app/mcp` |
| `taste` | Taste Profile | `https://taste.openkrill.app/mcp` |
| `openkrill-api` | Agent Tools API | `https://api.openkrill.app/mcp` |

Every server is public, read-only and needs no key.
