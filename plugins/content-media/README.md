# Content and Media Tools

Trending topics and post ideas, post and video script drafts, AI-writing checks, transcripts, free video, Live Photos, design taste, public views and likes of posts, plus YouTube transcripts, app reviews and X posts.

```bash
claude plugin install content-media@openkrill
```
